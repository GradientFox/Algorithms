# Стэк

В stack/stack.py реализован класс стека, импортируется в другие программы.

## Скобочки

stack/brackets.py - Проверка правильности скобочной последовательности
Тесты:
- "([{}]())" -> Последовательность верная
- "{[]()" -> Неверная последовательность
- "[(]" -> Неверная последовательность

## Обратная польская запись
stack/rpn.pu - калькулятор на основе обратной польской записи
Тесты:
- "3 4 2 * +" -> 11
- "2 3 5 6 + - /" -> 4
