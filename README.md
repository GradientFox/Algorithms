# Стэк

В stack/stack.py реализован класс стека, импортируется в другие программы.

## Скобочки

stack/brackets.py - Проверка правильности скобочной последовательности
Тесты:
- "([{}]())" -> Последовательность верная
- "{[]()" -> Неверная последовательность
- "[(]" -> Неверная последовательность

## Обратная польская запись
stack/rpn.pu - калькулятор на основе обратной польской записи
Тесты:
- "3 4 2 * +" -> 11
- "2 3 5 6 + - /" -> 4

# Очередь
В queue/queue.py реализован класс очереди.

## Очередь задач
В queue/task.py два класса Task и TaskQueue.
Task имеет один атрибут name, который описывает название задачи.
TaskQueue реализует работу задачника, добавлять задачи можно через метод add_task, взять задачу в работу через get_next_task()

# Графы
В graph/dfs_bfs.py реализован класс графа.
В графе есть 2 функции dfs и bfs, первая для поиска в глубину, вторая для поиска в ширину по графу.
